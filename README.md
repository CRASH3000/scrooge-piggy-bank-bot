# Скрудж-копилка

![Тут должна быть картинка, но ее нет(.](//media/Превью-Проекта.png "Превью.")

***Скрудж-копилка - это Telegram-бот для тех, кто хочет держать деньги под контролем без сложных таблиц и лишней рутины в духе Скруджа Макдака.***

Бот помогает быстро записывать доходы и расходы прямо в Telegram, следить за балансом, смотреть отчет за месяц и лучше понимать свои финансовые привычки.  


## Функцонал
- Запись доходов и расходов обычным сообщением в чате
- Выбор категории трат и поступлений
- Контроль текущего баланса своего хранилища
- Отображение уровня хранилища 
- Отчет за текущий месяц
- Бот реагирует на ваши доходы/расходы и дает советы по финансовой грамотности 
- Выгрузка историй операций в CSV
- Возможность начать учет заново, если нужно сбросить данные

## Запуск проекта локально

1. Клонировать репозиторий

2. Создать и активировать виртуальное окружение
```
macOS / Linux
python3 -m venv .venv
source .venv/bin/activate
```
```
Windows
python -m venv .venv
.venv\Scripts\activate
```
3. Установить зависимости
```
pip install -r requirements.txt
```
4. Создать файл .env.
В корне проекта создай файл .env и укажи токен бота:
```
BOT_TOKEN=your_telegram_bot_token
```
5. Запустить приложение
```
python main.py
```

## Пример использования

После запуска бота:

- Нажми /start
- Введи стартовый капитал
- Записывай доходы и расходы обычным вводом:
1000
+500
-250
